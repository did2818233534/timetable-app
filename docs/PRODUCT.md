# 产品行为

本文档定义当前版本的用户可见行为和业务规则，不记录开发过程或版本变更。

## 课程表与布局

- 主界面按星期列和节次行绘制表格，顶部显示所选周次及日期。
- 水平拖动时页面跟随手指移动，松手后吸附到相邻周。
- `periods` 决定一天的节数、上下课时间、行是否显示及可选分隔文字。
- `visibleDays` 决定候选星期列；`hideEmptyDays` 可进一步隐藏整学期完全无课的星期。
- 隐藏星期或节次只影响显示，不删除课程。

## 周次与灰显

`term.startDate` 是第一周周一。每条安排先受 `startWeek..endWeek` 限制，再使用以下规则：

1. 存在 `activeWeeks` 时，以明确列出的周次为准。
2. 否则按 `EVERY_WEEK`、`ODD_WEEKS` 或 `EVEN_WEEKS` 判断。
3. 最后排除 `excludedWeeks`。

格子优先显示所选周正在上的课程。当前周没有课程时，灰色显示最近将要上的课程；未来没有课程时，灰色显示最近上过的课程。

## 同格多课程与冲突

- 同一星期、同一节次可保存多条安排。
- 每个格子可独立选择单课程模式或上下分栏模式；分栏模式最多同时显示两门，更多课程以 `+N` 提示。
- 课程选择顺序依次为本周有效、最近未来、最近过去，并以安排 ID 保证稳定结果。
- 同一天的时间区间重叠且至少共享一个实际周次时构成冲突。
- 冲突不会阻止保存；应用弹出警告，并在显示课程区域左下角绘制小红点。上下分栏时标记位于下半格左下角。

## 编辑与课表库

- 点按空白格新增课程，点按有课格选择、编辑或删除安排。
- 长按课程复制，长按空白格粘贴；同格多课程时长按复制当前排序第一项。
- 新建课表从学期名称、第一周周一、总周数和节次时间开始。
- 应用可保存多份课表。新建和导入都会新增一份并自动切换，不覆盖已有课表。
- 右上角菜单集中提供切换、导入、导出、新建和设置。

## 导入与导出

- `.timetable.json` 保存完整课表、布局、同格显示和提醒设置，可重新导入。
- Android 文件选择器以及系统的“打开方式/分享”可以把 JSON 交给应用导入。
- 导入先完整解析并验证，成功后才新增到本地课表库；无效文件不会产生半成品数据。
- `.xlsx` 用于查看、打印或二次整理，包含周课表网格和课程明细，不作为应用导入格式。
- 详细字段见 [课表 JSON 格式](TIMETABLE_JSON_FORMAT.md)。

## 提醒

- 全局范围包括关闭、每节课和每天第一节课。
- 每条安排可以继承全局设置，也可以单独开启或关闭。
- 单独开启时可覆盖提前分钟数和提醒方式。
- 弹窗模式使用高优先级通知；闹钟模式使用持续响铃服务。
- 旧文件未配置提醒时默认关闭，不会因升级突然产生提醒。

## 桌面小组件

- 小组件从当天开始展示未来七天，而不是固定从周一开始。
- 小组件复用主应用的周次计算、显示星期/节次和同格课程选择规则。
- 普通 Android AppWidget 可直接侧载使用；进入小米小部件中心或负一屏专用入口仍需小米平台接入和审核。

## 平台范围

- 最低 Android 8.0（API 26），目标 Android 16（API 36）。
- 全新安装没有演示课表。
- 当前使用应用私有文件保存数据，用户课表不会进入源码仓库。
