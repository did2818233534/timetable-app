# 课程表应用任务规划书

## 1. 项目目标

开发一款本地优先的 Android 课程表应用，覆盖目标手机中小米课程表的主要能力，并支持澎湃 OS 2 桌面和负一屏小部件。课程数据可以在电脑上按固定模板编辑，再导入手机。

## 2. 核心范围

- 学期设置：开学日期、学期周数、当前周，以及由文件定义的每日节数和每节课上下课时间。
- 课程管理：名称、教师、教室、星期、节次、颜色和备注。
- 周数规则：每周、单周、双周、起止周和自定义周数。
- 课程表展示：切换周次；本周不上课的课程保留位置并显示为灰色。
- 编辑操作：新增、修改、删除，以及应用内长按复制粘贴。
- 文件交换：使用可编辑的 JSON 课表格式；已支持文件选择、校验、导入和持久化，后续补充预览与合并模式。
- 小部件：已提供从当天开始的未来七天表格；后续按需要补充“下一节课”和“今日课程”等尺寸。
- 提醒：可配置课前通知，并在重启、时间变化或课程更新后重建提醒。

## 3. 技术与分层

- `domain`：学期、课程、上课安排和周数规则等纯业务模型。
- `data`：Room数据库、设置存储、文件导入导出及仓库实现。
- `presentation`：Compose页面、导航、ViewModel和界面状态。
- `widget`：Android原生小部件及小米澎湃 OS 适配。
- `notification`：闹钟、通知和后台恢复逻辑。

主应用使用Compose，小部件优先使用 `AppWidgetProvider + RemoteViews`，以便控制网格布局并提高小米桌面兼容性。

## 4. 开发阶段

1. **基础数据**：已确定领域模型和仓库边界；下一步完成 Room 存储与迁移测试。
2. **主要界面**：周课程表、灰色状态、左右滑周、快速新增/编辑/删除和长按复制粘贴已完成；继续实现学期设置。
3. **导入导出**：JSON 覆盖导入已完成；继续实现导入预览、合并和备份恢复。
4. **小部件与提醒**：未来七天桌面表格已完成；继续完善尺寸适配、数据刷新和课前提醒。
5. **兼容与发布**：在真实澎湃 OS 2 手机上验证桌面、负一屏、深色模式和省电场景，再准备小米平台审核资料。

## 5. 验收重点

- 单双周、起止周和自定义周数计算正确。
- 同一课程可以有多组时间和教室，上课冲突能够被发现。
- 非当前周课程明确灰显，调课或停课不会破坏原始安排。
- 非法导入不会写入数据库，并能定位到具体行列。
- 应用被清理或手机重启后，小部件和提醒仍能恢复。
- 对照目标机中的小米课程表建立功能清单，逐项验收差异。

## 6. 已知外部事项

普通Android小部件可以直接开发和侧载测试；要稳定进入小米小部件中心及负一屏，需要后续使用小米开发者账号完成专用适配和审核。
